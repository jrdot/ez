# 사용자 요구사항 규격서

- 문서명: 사용자 요구사항 규격서
- 대상: 부품 배치 및 배선 연결 웹앱
- 기준 버전: Draft v0.1
- 기준 참고 서비스: easycable.co.kr/app
- 작성 목적: 사용자가 구상한 기능과 동작을 구현 전에 명확히 정의한다.

---

## 1. 시스템 목적

본 웹앱은 실제 부품 이미지와 단자 정보를 기반으로 부품을 배치하고, 단자 간 배선을 시각적으로 연결하며, 배선/부품 정보를 편집·관리할 수 있는 웹 기반 작업 도구를 목표로 한다.

---

## 2. 전체 화면 구성

### REQ-LAYOUT-001
웹앱은 다음 주요 영역으로 구성한다.

- 상단 헤더
- 좌측 사이드바
- 중앙 작업영역
- 우측 사이드바
- 하단 영역

### REQ-HEADER-001
상단 헤더는 다음 요소를 포함한다.

- 소형 로고 영역
- 작업 모드 변경 영역
- 현재 모드에 대응하는 고정형 도구상자

### REQ-MODE-001
기본 작업 모드는 다음 3종류를 지원한다.

- 마우스 모드
- 배선 모드
- 이미지 모드

### REQ-TOOLBOX-001
상단 도구상자는 고정 위치에 배치하며, 현재 선택된 작업 모드에 따라 표시 도구가 변경될 수 있다.

---

## 3. 좌측 사이드바

### REQ-SIDEBAR-L-001
좌측 사이드바의 주요 컴포넌트는 탭 형태로 구성한다.

기본 탭:

- 라이브러리
- 공용부품

### REQ-LIBRARY-001
라이브러리 탭은 다음 기능을 제공한다.

- 부품 추가
- 부품 목록
- 부품 수정
- 부품을 Canvas로 Drag & Drop하여 배치

### REQ-PUBLIC-LIBRARY-001
공용부품 탭은 웹서비스에서 미리 등록한 공용 부품 라이브러리를 제공한다.

### REQ-SIDEBAR-L-002
좌측 사이드바는 접기/펼치기 기능을 제공한다.

---

## 4. 우측 사이드바

### REQ-SIDEBAR-R-001
우측 사이드바는 현재 선택한 객체의 속성을 표시한다.

### REQ-SIDEBAR-R-002
우측 사이드바는 접기/펼치기 기능을 제공한다.

---

## 5. 중앙 작업영역

### REQ-CANVAS-001
중앙 작업영역은 Canvas 기반으로 구성하며, 라이브러리의 부품을 Drag & Drop으로 배치할 수 있어야 한다.

### REQ-CANVAS-SIZE-001
Canvas는 다음 규격을 지원한다.

- A4 가로
- A4 세로
- A3 가로
- A3 세로

기본값은 **A4 가로**로 한다.

### REQ-CANVAS-BG-001
Canvas 기본 배경색은 흰색으로 한다.

사용자는 System 설정에서 Canvas 배경색을 변경할 수 있어야 한다.

### REQ-GRID-001
Grid는 Canvas 좌표계에 고정한다.

### REQ-SNAP-001
Snap 기능은 다음 상태를 지원한다.

- 객체 Snap
- Grid Snap
- Snap OFF

기본값은 **객체 Snap**으로 한다.

### REQ-OVERLAP-001
객체 및 부품 간 겹침을 허용한다.

---

## 6. 프로젝트 및 작업 페이지

### REQ-PROJECT-001
하나의 프로젝트는 최대 3개의 작업 페이지를 제공한다.

### REQ-PAGE-NAME-001
작업 페이지 탭의 기본 명칭은 다음 형식을 사용한다.

- EZ-001
- EZ-002
- EZ-003
- 이후 동일한 규칙으로 3자리 번호 증가

---

## 7. 객체 모델

### REQ-OBJECT-001
Canvas의 기본 구성 단위는 객체(Object)로 정의한다.

기본 객체 타입:

- 이미지
- 선
- 점
- 텍스트

부품은 위 객체들의 조합으로 구성할 수 있다.

### REQ-OBJECT-ID-001
모든 객체에는 고유 Object ID를 부여한다.

### REQ-GROUP-001
복수 객체를 그룹화할 경우 그룹 자체에 새로운 Object ID를 발행한다.

그룹 내부 기존 객체의 ID는 유지한다.

---

## 8. 부품 및 단자

### REQ-TERMINAL-001
부품의 배선 연결 지점은 **단자(Terminal)** 로 정의한다.

### REQ-TERMINAL-002
하나의 단자에는 복수의 배선을 연결할 수 있다.

### REQ-TERMINAL-003
단자는 배선 편집 과정에서 직접 드래그하여 이동할 수 없다.

단자의 위치 수정은 부품/단자 편집 기능에서 수행한다.

---

## 9. 이미지 입력 및 편집

### REQ-CLIPBOARD-001
클립보드의 이미지를 Canvas에 붙여넣을 경우 자동으로 부품 추가 흐름과 연결한다.

### REQ-IMAGE-001
업로드한 이미지를 다듬기 위한 기본 이미지 편집 기능을 제공한다.

최소 기능:

- 이미지 자르기
- 배경 제거
- 크기 조정

---

## 10. 선택 및 기본 편집 조작

### REQ-SELECT-001
기본 선택 동작은 다음과 같다.

- Click: 단일 선택
- Ctrl + Click: 다중 선택 추가/해제
- Shift + Click: 다중 선택 추가/해제

### REQ-SHORTCUT-001
일반적인 편집 단축키를 지원한다.

예:

- Ctrl + C: 복사
- Ctrl + V: 붙여넣기
- Ctrl + X: 잘라내기
- Ctrl + Z: 실행 취소
- Ctrl + Y: 다시 실행
- Delete: 삭제
- Ctrl + A: 전체 선택
- Esc: 현재 선택 또는 작업 취소

---

## 11. 회전

### REQ-ROTATE-001
객체의 기본 회전은 마우스 Drag를 이용한 자유 회전으로 한다.

### REQ-ROTATE-002
Shift + Drag 시 45도 단위로 각도 Snap이 적용된다.

---

## 12. Canvas 탐색

### REQ-NAV-001
마우스 휠 동작은 다음과 같이 한다.

- Wheel: 상/하 스크롤
- Shift + Wheel: 좌/우 스크롤
- Ctrl 또는 Alt + Wheel: 확대/축소

### REQ-PAN-001
Canvas 이동(Pan)은 다음 조작을 지원한다.

- 휠 버튼 클릭 + Drag
- Space + Drag

---

## 13. 배선 기본 규칙

### REQ-WIRE-ENDPOINT-001
배선의 시작점과 끝점은 반드시 유효한 연결 대상에 닿아야 한다.

유효 연결 대상:

- 단자
- 분기점

### REQ-WIRE-TYPE-001
배선 타입은 다음 3종류를 지원한다.

1. 90도 직선
2. 45도 직선
3. 자유직선

### REQ-WIRE-FREE-001
자유직선은 시작점과 끝점을 하나의 직선으로 직접 연결한다.

중간 절곡점을 생성하지 않는다.

### REQ-WIRE-STYLE-001
배선은 다음 속성을 사용자 설정 가능하도록 한다.

- 색상
- 두께

---

## 14. 배선 절곡 및 위치 조정

### REQ-WIRE-EDIT-001
사용자가 배선의 선분을 Drag하면 필요한 절곡점과 꺾임을 자동 생성하여 배선 위치를 조정할 수 있어야 한다.

### REQ-WIRE-BEND-001
절곡점(Bend Point)은 배선 경로를 편집하기 위한 점으로 정의한다.

### REQ-WIRE-BEND-DELETE-001
절곡점을 삭제하면 인접 선분을 병합하고 가능한 범위에서 배선 경로를 자동 단순화한다.

### REQ-WIRE-BEND-MOVE-001
절곡점은 직접 선택하여 위치를 이동할 수 있다.

90도 배선의 절곡점 이동 방향:

- 상
- 하
- 좌
- 우

### REQ-WIRE-BEND-MOVE-002
45도 배선의 절곡점은 다음 방향 이동을 허용한다.

- 상
- 하
- 좌
- 우
- 좌상
- 우상
- 좌하
- 우하

단, 개발 난이도가 높은 경우 대각선 이동은 후속 버전에서 구현할 수 있다.

---

## 15. 분기점

### REQ-WIRE-JUNCTION-001
배선 중간에 분기점을 생성할 수 있어야 한다.

분기점은 화면에서 명확히 식별할 수 있어야 한다.

### REQ-WIRE-JUNCTION-002
분기점 후보는 다음 상황에서 발생한다.

- 새 배선의 시작점을 기존 배선 중간으로 지정할 때
- 새 배선의 끝점을 기존 배선 중간으로 지정할 때

### REQ-WIRE-JUNCTION-003
새 배선이 기존 배선 중간에 접근할 경우 Snap이 발생하며, 실제 생성 전에 쉐도우 형태의 분기점 미리보기를 표시한다.

### REQ-WIRE-JUNCTION-004
쉐도우 분기점을 클릭하여 확정하면 실제 분기점이 생성되고 새 배선이 해당 분기점에 연결된다.

---

## 16. 배선 교차 처리

### REQ-WIRE-CROSS-001
배선이 서로 교차하더라도 기본적으로 전기적으로 연결하지 않는다.

### REQ-WIRE-CROSS-002
분기점이 아닌 모든 배선 교차지점은 반원 형태의 Crossover/Jump 표시를 사용하여 비연결 상태임을 명확히 표현한다.

---

## 17. 배선 모드 쉐도우 미리보기

### REQ-WIRE-SHADOW-001
배선 모드에서는 휴먼에러 최소화를 위해 쉐도우 이미징(Preview)을 활성화한다.

적용 대상:

- 연결 가능한 단자
- 기존 배선의 분기점 후보
- 실제 생성될 배선 경로
- 90도/45도 꺾임 경로
- Snap 대상
- 교차 및 분기 상태

### REQ-WIRE-SHADOW-002
사용자가 클릭하여 확정하기 전에 실제 생성될 결과를 가능한 범위에서 미리 표시한다.

---

## 18. 하단 영역

### REQ-BOTTOM-001
하단 영역은 작업 보조 기능과 시스템 기능을 위한 고정 영역으로 확보한다.

작업 보조 기능:

- 확대/축소
- BOM View
- Table View
- Grid
- Snap
- Full Screen

시스템 기능:

- Code Download
- PDF Download
- PNG Download
- Help
- System

### REQ-BOTTOM-002
하단 영역에는 현재 선택한 객체의 요약 정보를 표시한다.

객체 정보 표시는 **1라인으로 제한**한다.

세부 속성은 우측 속성 패널에서 확인한다.
