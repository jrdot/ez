# FE-02 — 레이아웃, 페이지, Canvas 탐색

선행: FE-01의 좌표·페이지·상태 계약. 핵심 영역은 Header, 좌 Sidebar, 중앙 작업영역, 우 Sidebar, 하단이다.

## 구현 작업

1. Header에 작은 로고, Mouse/Wire/Image 모드 선택, 위치가 고정된 Mode Toolbox를 배치한다. 모드에 따라 내용만 바꾸며 활성 모드를 명확히 표시한다. 상세 도구 목록은 DES-TOOLBOX-001의 예시와 확정 필수 기능을 구분한다.
2. 좌측은 라이브러리/공용부품 탭과 접기·펼치기를, 우측은 선택 속성과 접기·펼치기를 구현한다. 접은 만큼 중앙 viewport가 넓어져야 한다.
3. 중앙 위에 작업 페이지 탭을 둔다. 새 프로젝트는 EZ-001에서 시작하고 최대 3개까지만 생성한다. 4번째 추가는 도메인에서도 거부한다. 페이지 전환 시 다른 페이지의 객체가 선택/편집되지 않게 한다.
4. 유한한 A4/A3 도면을 렌더링한다. 흰 배경과 문서 좌표에 고정된 Grid를 독립 레이어로 둔다. Sidebar/창 크기 변화는 도면 자체의 크기를 바꾸지 않는다.
5. 하단 선택 요약은 한 줄로 제한한다. 긴 이름은 잘림 처리를 하되 상세 속성은 우측에서 확인할 수 있어야 한다. Zoom/BOM/Table/Grid/Snap/Full Screen 및 Code/PDF/PNG/Help/System 진입 영역을 확보한다. 기능 구현은 해당 단계에서 연결한다.

정확한 높이·폭·색·아이콘은 미정이다. CSS 변수로 관리하고 작업 가능한 데스크톱 폭에서 접힘/넘침을 확인하는 것을 제안한다. 작은 화면 지원 범위를 확정하지 않은 채 모바일 지원 완료로 표기하지 않는다. 탭·버튼의 접근 가능한 이름, 활성 상태, 키보드 포커스를 제공한다.

## 입력 동작 계약

| 입력 | 확정 동작 |
|---|---|
| Wheel | 세로 스크롤 |
| Shift + Wheel | 가로 스크롤 |
| Ctrl 또는 Alt + Wheel | 확대/축소 |
| 휠 버튼 + Drag | Pan |
| Space + Drag | Pan |
| Snap 선택 | Object / Grid / Off, 기본 Object |

동시 modifier 충돌은 확대/축소 → 가로 → 세로 순을 제안한다. Canvas가 소비하는 이벤트에서만 브라우저 기본 동작을 억제한다. 속성 입력/대화상자에서 Space·Wheel이 편집기를 오작동시키지 않도록 이벤트 범위를 정한다.

모든 DnD·객체 이동·배선·hit test에서 같은 `client ↔ viewport ↔ world ↔ component local` 변환 함수를 사용한다. SVG의 실제 transform/여백까지 반영하며 bounding box의 단순 비례 계산만으로 처리하지 않는다. 포인터 위치를 중심으로 줌하고 화면상의 hit 영역·스냅 거리와 문서 좌표를 구분하는 것을 제안한다.

Object Snap의 대상·우선순위·임계값은 미정이다. 초기 제안은 연결 가능한 단자/분기와 객체의 정렬 기준점을 작업 문맥별로 선택하는 것이다. 후보 선택을 결정적으로 만들고 Preview와 확정에서 같은 결과를 사용한다. Grid Snap은 월드 좌표를 반올림하고 Off는 위치 보정을 하지 않는다. **Snap Off여도 배선 endpoint의 유효 연결 대상 제한은 유지한다.** 배선 중간 분기 후보의 명시적 Snap 요구와 일반 Snap Off의 관계는 FE-04 착수 전에 결정한다.

## 완료 기준과 검증

- 4가지 용지·방향을 전환해 도면 비율과 좌표가 유지되는지 확인. 크기 변경 시 경계 밖 객체 처리 정책은 사전 결정하고 자동 삭제하지 않음.
- 양쪽 Sidebar 접힘/펼침 뒤 DnD·hit test 위치가 일치.
- 줌·팬 뒤 Grid와 객체 상대 위치가 동일하고 Wheel modifier, 두 Pan 방식이 동작.
- 3페이지의 객체/선택이 섞이지 않음. 삭제/이름 변경 UI를 추가하면 번호 정책과 마지막 페이지 처리도 검증.
- 기본 Object Snap, Grid Snap, Off의 결과와 후보 Preview 확인.
- 자동 검증: 좌표 왕복·줌 중심·Grid Snap 도메인 테스트, 레이아웃·탭·입력 E2E. 시각 검증: 모드 강조·도구상자 고정·요약 한 줄.

인계: 좌표 API, 입력 우선순위, 스냅 후보 계약, 활성 페이지 API, UI 토큰과 미정 정책.
