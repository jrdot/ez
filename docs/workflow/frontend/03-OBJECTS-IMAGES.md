# FE-03 — 객체, 부품, 이미지 편집

선행: FE-01 명령·ID 계약, FE-02 좌표·선택 영역. 배선 개발에 사용할 실제 부품·단자 fixture를 이 단계에서 완성한다.

## 객체와 선택

1. Image/Line/Point/Text와 복합 부품을 렌더링한다. Line과 Point가 단지 배선·단자의 별칭이 되지 않도록 한다. 각 객체를 생성·수정하는 UI는 최소한의 검증 가능한 도구로 결정 기록에 남긴다.
2. Click은 단일 선택, Ctrl/Shift + Click은 각각 추가/해제다. 겹침을 허용하고 클릭 대상 우선순위는 z-order 등 일관된 정책으로 정한다.
3. 이동·삭제·속성 변경을 명령으로 실행한다. 회전은 Drag로 자유 회전, Shift + Drag로 45° 단위 스냅한다. 회전 중심과 그룹 변환 규칙을 공통 변환 함수로 처리한다.
4. 그룹 생성 시 새 그룹 ID를 발급하고 자식 ID를 유지한다. 그룹 해제 UI를 제공한다면 자식 ID·월드 위치 보존과 Undo를 검증한다.
5. 우측 속성 패널은 선택 타입에 맞게 표시하고 변경이 Canvas에 반영되게 한다. 미선택/단일/다중/그룹 선택의 상태를 구분한다. 다중 선택의 서로 다른 값은 혼합 상태로 표시하는 것을 제안한다.

## 단축키

| 입력 | 구현 동작 |
|---|---|
| Ctrl+C / Ctrl+X / Ctrl+V | 선택 복사 / 잘라내기 / 붙여넣기 |
| Ctrl+Z / Ctrl+Y | Undo / Redo |
| Delete | 선택 삭제 |
| Ctrl+A | 활성 페이지 전체 선택 |
| Esc | 진행 작업 취소, 진행 작업이 없으면 선택 해제 제안 |

입력창·contenteditable·대화상자에서는 문자 편집 단축키를 보존한다. 내부 객체 붙여넣기와 외부 이미지 붙여넣기를 payload로 구분한다. 복사한 하위 객체는 새 ID와 내부 endpoint 참조를 함께 재매핑한다. 선택 범위 밖 배선/단자의 복사·삭제 처리는 미정이므로 FE-04와 같은 정책을 사용한다. 잘라내기는 복사 데이터 확보 뒤 삭제한다. 한 사용자 조작을 한 번의 Undo로 복구한다.

## 라이브러리와 Terminal

- 개인 라이브러리: 추가, 목록, 수정, Canvas로 Drag & Drop 배치.
- 공용부품: 서비스 사전 등록 부품 목록을 제공하는 읽기 어댑터. API가 없으면 샘플 데이터 사용임을 명시한다. 검색/분류·계정·공용 등록 관리 정책은 별도 결정 전 구현 범위에 넣지 않는다.
- 부품 정의와 인스턴스를 구분한다. 등록 부품 수정이 기존 배치에 자동 전파되는지 결정하고, 사용자 편집이 공용 원본을 바꾸지 않게 한다.
- Terminal은 ID, 로컬 X/Y, 이름, 표시/연결 가능 여부를 가진다. 부품/단자 편집 UI에서 위치를 수정할 수 있다. 배선 모드에서는 직접 드래그할 수 없다.
- 부품 이동/회전/크기 변경 시 단자 월드 위치도 변환된다. 연결 배선 endpoint 갱신 및 경로 보정은 FE-04 계약으로 이어진다.

## 이미지 입력과 편집

제안 흐름: `파일 업로드 또는 이미지 Paste → 부품 추가 초안 → Crop/배경 제거/Resize → 단자·이름 편집 → 등록 → 배치`. 원문은 붙여넣기의 부품 추가 연결만 확정하므로 등록 후 자동 배치 여부와 Wizard 순서는 결정 기록에 남긴다.

- 원본과 편집 결과를 구분하고 임시 작업 취소 시 미완성 부품·고아 자산을 남기지 않는다.
- Crop/Resize의 좌표 변환을 Terminal에도 적용하는지, 단자를 재배치하게 할지 결정한다. 보이지 않는 위치에 단자를 조용히 남기지 않는다.
- 배경 제거는 결과의 실제 투명도를 검증한다. 단순 배경색 변경으로 대체하지 않는다. 브라우저 처리/외부 서비스, 품질 기준·용량 제한은 미정이며 어댑터 선택 전에 확인한다.
- MIME·디코딩 실패, 지원하지 않는 형식, 클립보드 접근 실패, 작업 취소, 비동기 처리 중 재입력을 처리한다. 크기/용량 제한은 설정 가능한 구현 선택으로 기록한다.
- 임시 blob URL만 파일에 저장하지 않는다. 자산 보존은 FE-05 계약과 맞춘다. 비동기 작업 중 프로젝트가 바뀌면 이전 프로젝트 결과를 현재 문서에 삽입하지 않는다.

## 완료 기준

- 이미지 포함 부품을 등록·수정하고 줌/팬 후 DnD해 정확한 위치에 배치.
- 기본 4객체·그룹 ID·다중 선택·회전·속성·단축키가 검증됨.
- 이미지 Paste가 부품 추가로 연결되고 Crop/Resize/배경 제거의 실제 결과와 취소가 확인됨. mock이면 해당 기능 완료로 표시하지 않음.
- 여러 인스턴스의 단자 ID가 충돌하지 않고 이동/회전 후 단자 좌표가 정확함.
- 도메인 테스트: ID 재매핑·그룹 변환·회전 스냅·이력. UI/E2E: 등록→배치→선택→편집→Undo/Redo, 폼 입력 중 단축키 보호.

인계: 이미지·복합 부품·연결 가능/불가 단자가 포함된 fixture, 단자 hit test, 라이브러리/자산 어댑터와 미정 계약.

## 구현 결과 (2026-09-23)

[FE-03 인계](03-OBJECTS-IMAGES-HANDOFF.md)에 구현·API·fixture·검증·제한을 기록했다. 배경 제거는 사용자 지시로 **외부 AI 연동 확정까지 대기**한다. Crop/Resize, 객체·부품·단자 편집과 라이브러리는 구현했으며, 공용 목록은 샘플 상태다. 배경 제거까지 포함한 원래 완료 기준 전체가 충족되었다고 표시하지 않는다.
